Use it as the Steam startup movie

  1. Put the .webm file in ~/.steam/root/config/uioverrides/movies/. Create the folders if they don’t exist.
  2. In Steam, open Settings > Customization > Startup Movie and pick it.

Which file to ship

Ship the dark version: it hands off to the Steam library without a bright flash. The bundled 1280×720 cuts (30 and 60 fps) are the safe default; higher-resolution exports are for sharing. Steam needs the .webm; the .mp4 files are for sharing. Everything is drawn and synthesized in code, so the included scripts can output any other size.
