# DroidHost 0.1.2

**A session-UX release: the portrait key toolbar, input and display fixes, on top of the Arch / flatpak-host groundwork landed since 0.1.1.**

Install it over 0.1.1 — same signing key, so no uninstall and no data loss.

## Session toolbar & input

- Redesigned portrait key toolbar: a left slide-out modifier cluster (Esc / Tab / Ctrl / Alt / Super / Shift …) plus a right fixed cluster — keyboard toggle, a gear config panel, and a ThinkPad-style arrow cluster.
- Gear config panel: guest UI scale (100 / 150 / 200%) and a Performance HUD on/off row.
- The keyboard toggle stays highlighted while the soft keyboard is open.
- The soft keyboard no longer auto-hides when a guest text field loses focus, so long menus (e.g. Firefox dropdowns) stay open instead of jumping / shrinking. Tapping a text field still raises it.
- Chinese / CJK input goes through the guest file-clipboard path so it lands reliably.
- Super: single tap triggers, double tap holds.

## Display & HUD

- The refresh-rate picker offers the panel's real peak (e.g. 144 Hz) explicitly, and the auto entry reads "Auto · <hz> Hz".
- The Performance HUD docks to the right edge by default — a small FPS tab you tap to expand — instead of floating over the desktop. Toggle it from the gear panel.

## Since 0.1.1: Arch + flatpak host + app identity

- Arch Linux runtime / preset in CI, and a flatpak-based desktop host (KWin / gamescope) for the general-Linux desktop focus.
- VM lifecycle fixes: runtime gate, session re-entry, desktop autostart.
- DroidHost identity: stripped the game-launcher surface and shipped the new logo.

## Early software

This is an early fork. The general-Linux / desktop path is the focus; game-specific surfaces are being removed. Expect rough edges, and please report what breaks with your device + Android version.
