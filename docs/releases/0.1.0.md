# DroidHost 0.1.0

**A real Linux desktop on your Android phone or handheld.**
DroidHost runs an ARM64 Linux runtime under an in-app Vulkan compositor and gives you a desktop
session on the device — a general-purpose Linux environment, with the guest running as ARM code,
not x86 emulation.

This is the **first release under the DroidHost name**. DroidHost is a GPL-3.0 fork of
[DroidDeck](https://github.com/Droid-Deck/DroidDeck). It keeps the upstream runtime, credits and
licence, and now ships on its own release channel with its own in-app updates. DroidHost's focus
is the general-purpose Linux / desktop path.

> **Early software.** The runtime and desktop are inherited from DroidDeck and have been run on
> real hardware there, but this is DroidHost's first release and not everything has been
> re-verified on every device. Where something has not been tested, treat it as untested.

---

## What it does

- **Linux runtime.** An ARM64 Linux guest under proot, presented through the in-app Vulkan
  compositor (gamescope).
- **A desktop on your device.** Start a Linux desktop session on your phone or handheld and use
  it as a general-purpose Linux environment.
- **Touch as a touchpad.** On the desktop, touch acts as a touchpad for pointer control.

## What is DroidHost's own

- **Its own release channel and in-app self-update**, served from the fork's own catalog.
- **Add-on packs and components** published to the fork's own components repository.
- Graphics driver binaries (Turnip and friends) are still fetched from the upstream driver
  catalog, so driver updates keep arriving.

## Installing

Download the APK below and install it. On first launch it downloads the Linux runtime (once).

**Requirements:** an arm64 Android device with a Vulkan-capable GPU — Adreno with Turnip is the
best-tested path — and a few GB free for the runtime.

## Known limits

This is early software built on a proot guest and a stand-in GPU: some paths composite in software,
and some display changes apply at the next session rather than immediately. See the repository
docs for the current device-support and limitation notes.
