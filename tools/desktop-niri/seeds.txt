# qt6-base 6.12 links libcrypto.so.4 (OPENSSL_4.0.0) but its pacman depends name plain "openssl",
# which closure.py serves from the base's openssl 3.6.3 (.3 only) and so does NOT ship the 4.1.0
# upgrade. Seed the .4 soname to force core/openssl-4.1.0-1 into the pack (replacing the base

# Hyprland's libzip. Without this seed qt6-base's libcrypto.so.4 is unsatisfied and DMS fails to start.
